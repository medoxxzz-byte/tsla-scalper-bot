# اعتماد حي — الصفقة الممتدة الورقية في Dashboard

**التاريخ:** 1 أكتوبر 2026
**الإصدار:** `extended-paper-v1`
**نطاق الاعتماد:** محرك ورقي مستقل في Dashboard فقط، وليس V17/V18 أو واجهة `/manual` أو تداولاً حقيقياً.

## ما طُبّق في الإنتاج

1. طُبّق ترحيل Neon غير الهدمي `005_create_extended_paper_trade_ledger.sql`.
2. أُنشئ جدولان منفصلان:
   - `extended_paper_trades`: ملخص قرار الصفقة، العقد، القياسات، والخروج.
   - `extended_paper_trade_events`: سجل append-only للأحداث.
3. نُشر الالتزام `d33f931` على Render.
4. ظهرت بطاقة **الصفقة الممتدة الورقية — Dashboard فقط** في `/dashboard`، ويجلب المتصفح حالتها من `/extended-paper/status`.

## فحص الحماية الحي

| بند | النتيجة |
|---|---|
| اتصال endpoint الحالة | ناجح (`HTTP 200`) |
| حالة المحرك | `running=true` و`enabled=true` |
| بيئة التنفيذ | `paper_only=true` |
| آخر قرار | `NO_TRADE` بسبب عدم اتفاق واضح بين 15د و5د |
| مركز مفتوح | لا يوجد |
| دفتر Neon عند الفحص | 0 صفقة و0 حدث |
| قيد صفقة واحدة لكل يوم نيويورك | موجود (`UNIQUE(trade_date)`) |
| قيد عقد واحد فقط | موجود (`option_quantity = 1`) |
| حظر البيئة غير الورقية | موجود (`execution_environment = alpaca_paper`) |
| النسخ الاحتياطي والاستعادة | نجحا بعد إدراج الجدولين الجديدين |

## السلوك التشغيلي المعتمد

- فترة تقييم القرار: **09:50–14:30 ET**.
- يختار المحرك CALL أو PUT فقط عند توافق 15د و5د، مع قرب من VWAP وموافقة RSI.
- إذا لم تتكامل الشروط، يسجل الحالة `NO_TRADE` ولا يفتح صفقة ولا يرسل تنبيهاً مزعجاً.
- عند دخول طبيعي، يستعمل عقداً واحداً ITM من 1DTE أو أقرب يوم تالٍ، ويقيس امتداد TSLA عند `$0.30` و`$0.60` و`$1.20` ثم يغلق وفق الإلغاء أو الهدف أو 15:50 ET.
- التنفيذ محصور في Alpaca Paper؛ لا توجد أي صلاحية تداول حقيقي في هذا النطاق.

## الحد الفاصل البحثي

القبول التقني مكتمل. أما **القبول الحقلي** فلا يبدأ إلا بعد أول دورة طبيعية كاملة: قرار → دخول ورقي → قياس/خروج → سجل Neon. النتيجة الأولى، سواء ربحاً أو خسارة، ليست حكماً على الاستراتيجية؛ هي فقط أول صف مراقب في العينة.
