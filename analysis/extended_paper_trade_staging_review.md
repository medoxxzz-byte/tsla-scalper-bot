# مراجعة قبول «الصفقة الممتدة الورقية» — Neon المؤقتة

**التاريخ:** 1 أكتوبر 2026
**النطاق:** بطاقة Dashboard مستقلة + محرك Alpaca Paper + دفتر Neon مستقل.
**لا يشمل:** `/manual` أو V17/V18 أو أي حساب حقيقي.

## ما اختُبر

| اختبار | النتيجة |
|---|---|
| شروط الاتجاه المتفق (15د و5د) قرب VWAP | نجح؛ ينتج CALL/PUT فقط عند توافق الشروط |
| منع مطاردة السعر بعيداً عن VWAP | نجح؛ القرار `NO_TRADE` |
| منع القرار خارج 09:50–14:30 ET | نجح |
| حظر endpoint غير الورقي | نجح؛ لا يُسمح بتنفيذ خارج `paper-api` |
| اختيار عقد ITM من 1DTE أو أقرب يوم تالٍ | نجح في اختبار معزول |
| معرف أمر يومي ثابت | نجح؛ يقلل تكرار أمر الدخول |
| عزل Dashboard عن `/manual` | نجح باختبار بنيوي؛ لا توجد نقطة تنفيذ مشتركة |
| سلامة اختبارات المشروع القديمة | نجحت ضمن مجموعة **55 اختباراً محلياً** |
| إنشاء الجدولين المؤقتين | نجح على فرع Neon مؤقت |
| قيد صفقة واحدة لكل تاريخ نيويورك | نجح؛ المحاولة الثانية أعادت الصف نفسه بلا إنشاء جديد |
| أحداث القياس +$0.30 و+$0.60 | نجحت؛ تُسجل مرة واحدة فقط |
| إغلاق صفقة الاختبار وحفظ P&L | نجح |
| النسخ الاحتياطي قبل الترحيل | نجح؛ بقي متوافقاً مع القاعدة الحية بلا جدولي المرحلة الجديدة |

## الحماية المتحققة

1. التنفيذ لا يبدأ إلا على `paper-api.alpaca.markets`.
2. الجدول يفرض `execution_environment = alpaca_paper` و`option_quantity = 1`.
3. القيد `UNIQUE(trade_date)` يمنع صفقة ممتدة ثانية حتى بعد إعادة تشغيل Render أو وجود أكثر من process.
4. لا يعيد المحرك محاولة دخول فاشل في اليوم نفسه؛ يحتفظ بسجل `entry_failed`.
5. الخروج الزمني 15:50 ET، والإلغاء يعتمد إغلاق شمعة 5 دقائق مكتملة فقط.
6. رسائل Telegram محصورة في الفتح، قياسات الامتداد، النتيجة، أو خطأ التنفيذ.

## ما لم يُختبر بعد

لا توجد صفقة سوق طبيعية للآلية بعد. القبول الحقلي لا يبدأ إلا بعد تشغيلها في الإنتاج ووصول أول قرار طبيعي ثم دخول ورقي ونتيجة مسجلة. لا يجوز اعتبار نتيجة اختبار Neon أو Mock دليلاً على جودة الاستراتيجية.

## قرار الترحيل

الترحيل **غير هدمي**: يضيف فقط `extended_paper_trades` و`extended_paper_trade_events` وفهارسهما.
ما زال يتطلب موافقة صريحة لتطبيقه على Neon الحية، وبعدها يُنشر الالتزام على Render ويُفحص endpoint `/extended-paper/status` قبل أن يسمح المحرك لنفسه بأي تنفيذ ورقي.
